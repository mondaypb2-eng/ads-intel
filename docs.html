ระบบรับไฟล์รายงานโฆษณาจาก Meta, Google และ TikTok ที่ใช้ชื่อคอลัมน์ไม่เหมือนกัน แล้วรวมเป็นข้อมูลชุดเดียว บอกว่าแคมเปญไหนควรขยายงบ ควรปรับปรุง หรือควรหยุด เสนอแคมเปญใหม่ จากนั้นสร้างรายงานสรุปขนาด 1080×1350 เป็นไฟล์ PNG ให้ส่งต่อได้ทันที

    รายงานภาพถูกออกแบบให้ล้นกรอบไม่ได้

    เทมเพลตแบ่งหน้า 1350px เป็น 5 ช่วงที่สูงคงที่ ชื่อแคมเปญที่ยาวเกินจะถูกตัดด้วย "…" และถ้ามีมากกว่า 6 แคมเปญจะเขียนว่า "+ อีก N แคมเปญ" แทนที่จะยืดหน้า

    ก่อนแคปภาพ ระบบเปิดหน้าใน Edge แบบ headless ขนาด 1080×1350 แล้ววัดสามอย่าง: ความกว้าง/สูงจริงของหน้า, กล่องไหนมีเนื้อหาเกินกล่อง และ Tailwind โหลดสำเร็จไหม ถ้าเลือกให้ Claude ออกแบบ HTML แล้วไม่ผ่านการวัดนี้ ระบบจะใช้เทมเพลตแทนและบันทึกเหตุผลไว้

    ทดสอบแล้วว่าตัววัดจับได้ทั้งเนื้อหาที่ล้นในกล่อง (200px ใส่เนื้อหา 600px) และหน้าที่ใหญ่เกินกรอบ (1200×1500)

    ผลการทดสอบ (Eval): ผ่าน 5 จาก 5 เคส

    รันในโหมดกฎ ใช้อัตราแลกเปลี่ยนคงที่ในการทดสอบ (USD 34, EUR 37, SGD 25.5) เพื่อให้คำตอบที่คาดไว้ไม่เปลี่ยนตามค่าตั้งค่า

    เคสสิ่งที่ทดสอบค่าที่คาดไว้ (บางส่วน)ผล

    ทุกเคสตรวจ 3 เกณฑ์ตามโจทย์: ทุกแถวผ่าน schema และไฟล์ JSON ไม่มี NaN/INF · ROAS, CPA และยอดรวมตรงกับค่าที่คำนวณมือ (คลาดได้ไม่เกิน 0.005) · รายงานเรนเดอร์ได้ 1080×1350 พอดีและแคป PNG ได้

    ผลจากข้อมูลตัวอย่าง

    เป็นข้อมูลจำลองของแบรนด์สกินแคร์ 10 แคมเปญ ช่วง 1–14 พ.ย. 2026 ใช้สาธิตเท่านั้น

    แพลตฟอร์มงบรายได้ROAS

    ได้สถานะขยายงบ 3, ปรับปรุง 3 และหยุด/ลดงบ 4 แคมเปญ และระบบจับสัญญาณที่ฝังไว้ในข้อมูลได้ครบ: Creative Fatigue ใน SunScreen_Reels_Lookalike, CPA พุ่งช่วงหลังใน Search - Generic - Sunscreen และแคมเปญไม่มี conversion TT_AcneGel_Awareness_TopView

    วิธีใช้งาน

    1. เปิด XAMPP Control Panel แล้วกด Start ที่ Apache
    2. เข้า http://localhost/ads-intel/ (มีทางลัดในโฟลเดอร์ "งาน")
    3. ถ้าจะใช้ Claude ให้ไปหน้า ตั้งค่า ใส่ Anthropic API key แล้วกด "ทดสอบการเชื่อมต่อ"
    4. อัปโหลดไฟล์ CSV/JSON ได้หลายไฟล์พร้อมกัน หรือติ๊ก "ใช้ข้อมูลตัวอย่าง"
    5. แก้รายการสินค้า/บริการ ซึ่งใช้หาแคมเปญใหม่ที่ควรยิง
    6. กด "เริ่มวิเคราะห์" แล้วดาวน์โหลด PNG, HTML หรือ JSON จากหน้าผลลัพธ์

    รันจาก command line ได้ด้วย: C:\xampp\php\php.exe tools\eval_cli.php หรือ tools\cli_run.php --ai

    สิ่งที่ต้องรู้ก่อนใช้งานจริง
